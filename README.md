# 深淵環オルビア（SHIN'ENKAN ORBIA）

深淵環の力をめぐり、環の継承者どうしがオーブとカードで競う対戦ゲーム。

**公開URL**：https://rikuink000-collab.github.io/core-abyss/

iPhone の Safari（縦画面）向けの、1人用カードバトル（vs CPU）です。ブラウザで開くだけで遊べます。ホーム画面に追加すると、アプリのように起動できます。

## 世界観

- **深淵環**：その力をめぐって、環の継承者どうしが競い合います。
- **オーブ**：対戦で使う資源。カードを使うときに支払い、ユニットに載せて強化します。
- **3つの属性**
  - **紅**：破壊と意志
  - **蒼**：知恵と流転
  - **翠**：生命と循環
- **プレイヤー**：環の継承者。同じく継承者である相手と対戦します。

## 遊び方の概要

- **勝ち方**：相手のライフ（5）を0にするか、相手が山札からカードを引けなくなったら勝ちです。
- **準備**：デッキは36枚（同名3枚まで）。対戦の前に、4つのデッキスロットから使うデッキを選びます。手札4枚、ストックにオーブ4個から始まります。先攻・後攻はランダムです。
- **デッキ編集**：タイトルの「デッキ編集」で、4つのスロット（初期状態は 標準／紅軸／蒼軸／翠軸）を自由に組み替えられます。CPUは4つの初期デッキからランダムに選びます。
- **ターンの流れ**
  1. コアステップ：ストックにオーブが1個増える（先攻の最初のターンだけは増えない）
  2. ドローステップ：1枚引く（後攻の最初のターンだけ2枚）
  3. リフレッシュステップ：自分のユニットが回復し、使ったオーブがストックに戻る
  4. メインステップ：ユニットの召喚、マジック、領域の設置、バーストのセット、オーブの移動
  5. アタックステップ：ユニットで1体ずつアタックする（先攻の最初のターンはアタックできない）
- **オーブとレベル**：カードはオーブで支払います。場にいる同じ属性のユニットなどが持つシンボルで、支払いが軽くなります。ユニットにオーブを多く載せるとレベルが上がり、BP（強さ）が上がります。
- **アタックとブロック**：アタックされた側は、自分のユニット1体でブロックできます。BPの高い方が残り、同じなら両方が破壊されます。ブロックしなければライフが1減ります。
- **フラッシュ**：ブロック宣言の前と後に、防御側から交互に、マジックや「迅雷」を持つユニットの召喚、場のユニットの効果を差し込めます。
- **バースト**：裏向きにセットしておき、ライフが減ったときや、自分のユニットが相手によって場を離れたときに、無料で発動できます。
- **自動パス**：フラッシュの確認を出すタイミングを「設定」で選べます。

## ファイル構成

- `index.html`：ゲーム本体（単一HTML。外部ライブラリなし）
- `img/`：カードイラスト
- 戦績と自動パス設定は `coreabyss_save_v1`、画面設定は `coreabyss_ui_v1`、デッキは `coreabyss_deck_v1` として、ブラウザの localStorage に保存されます
